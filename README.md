# X-10A42V-DDSB-PSU - DUAL IN ONE 10A 42V DC SYMMETRICAL PSU FOR POWER AMPLIFIER IN DOUBLE-SIDED CIRCUIT BOARD

X-10A42V-DDSB-PSU is a dual in one PSU circuit module in one double-sided circuit board designed to supply the operating voltage for power amplifier main-circuit module such as [X-B120W-4](https://github.com/X-ANONYMOUS-POWER-AMPLIFIER/X-B120W-4) and/or [X-B120W-4-LITE](https://github.com/X-ANONYMOUS-POWER-AMPLIFIER/X-B120W-4-LITE). It provides split dual 42V DC symmetrical outputs with 10A DC current handling capability applies GBU1006 rectifier diodes, 12V DC non-symmetrical output, and 15V DC symmetrical outputs.

This PSU circuit module provides advanced groundings specialized for power amplifier as: audio grounds, power/PSU grounds, and chassis grounds. It is completed with inrush current limiter applies 7 ohms - 15 Amperes Inrush Current Limiter (NTC Thermistor) type MS32-7R015 product from Vishay / Ametherm. It also completed with AC power entry socket PCB that can be applied for Bulgin AC Power Entry Modules Flange Mount IEC Fused Inlet model PF0002-28.

![X-10A42V-DDSB-PSU schematic diagram](https://github.com/X-ANONYMOUS-POWER-AMPLIFIER/X-10A42V-DDSB-PSU/blob/main/X-10A42V-DDSB-PSU-DUAL-IN-ONE-10A-42V-SYMMETRICAL-PSU-FOR-POWER-AMP.png)

Note about PCB:
The physical PCB can be split into 4 pieces by cutting on the breakaway-tabs.
